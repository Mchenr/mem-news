# Agent Memory 周报 · 2026-09-14

观察区间：2026-09-07 至 2026-09-14（Asia/Shanghai）

## 本周摘要

- **OpenViking 把资源访问控制带入稳定版**：v0.4.18 新增资源级 ACL、用户/组授权和分页过滤；v0.4.19 又加入受限 ACL 继承、受限 Python DSL 抽取与 Agent Experience。升级需处理 `acl_enabled`、`--tag` 等 Breaking Change，并重新评估 `cp/mv` 覆盖语义。
- **Mem0 的 Agent 插件边界收紧**：Pi、OpenCode、OpenClaw、DeepSeek 插件发布新版本，统一了准备、脱敏、作用域和遥测；Dream consolidation 与相关命令被移除。默认分支随后把 Sidekick 收窄为 Claude Code 专属，尚未证明进入 Release。
- **ReMe 把主动刷新从 auto dream 中拆出**：默认分支合并独立 proactive refresh 管线、每日 18:00 默认任务和 tag-filtered hybrid search；公共 dream topic schema 被移除，且默认部署会新增每日一次 LLM 调用。以上尚未证明发布。
- **多租户和存储边界继续修正**：Graphiti v0.30.2 修复并发 `multi-group_id` 隔离与按组清理遗漏；Hindsight 合并 store-owned bank 的附件返回能力，但稳定 core Release 仍停留在 v0.9.2。
- **Supermemory 的开源产品面收缩**：主站 Web 应用改为导向 hosted console 的重定向壳，仓库内 browser extension workspace 被移除；这改变了自托管/开源部署边界，但不是新的 server Release。

## 固定跟踪项目

### 1. OpenViking

- **已发布功能**：[v0.4.18](https://github.com/volcengine/OpenViking/releases/tag/v0.4.18) 引入资源级 ACL、用户/组授权、`ls/tree` 分页与排序、tag 过滤、filter-only `find`，并支持本地 VectorDB 安全追加 schema；[v0.4.19](https://github.com/volcengine/OpenViking/releases/tag/v0.4.19) 增加受限 ACL 继承、默认受限 Python DSL 抽取、外部任务生命周期托管和 Agent Experience。
- **Breaking Change**：`acl_enabled` 布尔值改为 `acl_mode` 字符串，CLI 可重复 `--tag` 改为逗号格式 `--tags`；`cp/mv` 允许覆盖/合并且回滚是弱保证，空源会被拒绝。依赖旧参数或假设“目标存在即失败”的调用方需要迁移。
- **部署边界**：ACL 默认关闭；已有远程 VikingDB collection 需要运维方预建 ACL 字段和索引，本地/cuVS 才会安全自动追加。升级前应备份覆盖目标并先在非生产环境演练。

### 2. MemOS

**无关键变化。** core 仍为 [v2.0.33](https://github.com/MemTensor/MemOS/releases/tag/v2.0.33)；[local plugin v2.0.19](https://github.com/MemTensor/MemOS/releases/tag/memos-local-plugin-v2.0.19) 只恢复 OpenClaw 安装与自动 memory hooks，属于集成可靠性修正，没有新的记忆模型、API 或 Breaking Change。

### 3. Graphiti

- **已发布正确性边界**：[v0.30.2](https://github.com/getzep/graphiti/releases/tag/v0.30.2) 为并发 `multi-group_id` 请求使用 request-scoped driver，并修复多组分支的命名参数绑定；多租户调用不再共享容易串扰的驱动状态。
- **删除语义**：按 `group_ids` 清理现在包含 Saga nodes；此前把“组已清空”当作完整删除保证的部署，应检查是否遗留 Saga 数据。FalkorDB edge full-text search 也避免了全量 Entity scan。

### 4. Letta

**无关键变化。** 固定仓库 `letta-ai/letta` 在观察区间只有文档和安全联系方式调整，没有默认分支功能提交或新 GitHub Release；该结论不覆盖 Letta Code、其他仓库或托管服务。

### 5. Hindsight

- **已合并、未证明稳定 core 发布**：[PR #4321](https://github.com/vectorize-io/hindsight/pull/4321) 让 recall、memory list/get、documents/chunks 对 store-owned bank 返回附件，不再要求查询 `memory_units`，补齐不同存储后端的读取语义；已知限制是这类附件的 filename 可能为空。
- **发布边界**：稳定 core Release 仍为 [v0.9.2](https://github.com/vectorize-io/hindsight/releases/tag/v0.9.2)。仓库同时出现 coding-agents v0.6.0 的发布提交、reflect 失败回退到 knowledge pages/observations、旧 `hindsight-memory` Claude 插件告警等变化，但不能据此宣称 core 已发布。

### 6. Mem0

- **已发布插件**：[Pi Agent v0.3.0](https://github.com/mem0ai/mem0/releases/tag/pi-agent-v0.3.0)、[OpenCode v0.3.0](https://github.com/mem0ai/mem0/releases/tag/opencode-v0.3.0)、[OpenClaw v1.1.0](https://github.com/mem0ai/mem0/releases/tag/openclaw-v1.1.0) 与 [DeepSeek v0.3.0](https://github.com/mem0ai/mem0/releases/tag/deepseek-plugin-v0.3.0) 复用统一的准备、脱敏、作用域和遥测基础层。
- **Breaking Change / 默认值**：Pi、OpenCode、OpenClaw 移除 Dream consolidation 及相关命令、技能或调度；DeepSeek 默认开启 system-prompt recall 与 durable session 自动 capture，跨用户 `userId` 覆盖则改为必须显式 `allowUserOverride: true`。
- **已合并、未证明发布**：[Sidekick 收窄提交](https://github.com/mem0ai/mem0/commit/d873892) 将 Sidekick 设为 Claude Code 专属；Cursor、Kimi、Antigravity 和 portable 包移除 Sidekick/hooks，记忆检索与技能仍保留。Codex 保留 native subagent memory，官方文档标为 Unreleased。

### 7. Cognee

**无关键变化。** 固定仓库在观察区间没有默认分支提交或新 GitHub Release；最新稳定版仍为 [v1.5.4](https://github.com/topoteretes/cognee/releases/tag/v1.5.4)，上期已覆盖其 `add` 签名、Git URL 摄取和本地文件根目录默认值变化。

### 8. ReMe

- **已合并、未证明发布**：[PR #488](https://github.com/agentscope-ai/ReMe/pull/488) 将 proactive refresh 从 auto dream 中拆成唯一写入 `daily/<date>/interests.yaml` 与 `daily/_proactive.yaml` 的管线，新增本地 one-shot 命令和默认每日 18:00 cron；旧数据仍可读，但公共 dream topic schema 被直接移除。
- **成本与迁移边界**：auto dream 不再拥有 proactive state；默认配置会新增每日一次 LLM 调用。依赖旧 topic schema 的插件必须迁移，并应显式评估定时调用预算。
- **检索能力**：默认分支还合并 [tag indexing 与 filtered hybrid search](https://github.com/agentscope-ai/ReMe/pull/530)，但稳定 Release 仍为 [v0.4.1.11](https://github.com/agentscope-ai/ReMe/releases/tag/v0.4.1.11)。

### 9. Supermemory

- **已合并、未证明 server 发布**：[PR #1651](https://github.com/supermemoryai/supermemory/pull/1651) 将 `app.supermemory.ai` 的插件、OAuth、邀请路径 308 重定向到 hosted console，其余页面只保留迁移提示；仓库内 browser extension workspace 被移除，API key 文档也改指 console。
- **部署边界**：这表明开源仓库中的 Web/extension 产品面进一步收缩，hosted console 成为主入口；最新 server Release 仍为 [server-v0.0.8](https://github.com/supermemoryai/supermemory/releases/tag/server-v0.0.8)，不能把部署变化写成新的服务版本。
