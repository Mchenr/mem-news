# Agent Memory 周报 · 2026-08-31

观察区间：2026-08-24 至 2026-08-31（Asia/Shanghai）

## 本周摘要

- **最重要的 Breaking Change**：OpenViking v0.4.17 移除 uid-less `viking://user/...` URI，必须迁移到 `viking://~/...` 或显式 user id；Cognee v1.5.3.dev1 改写并移动 Postgres graph adapter，但它仍是预发布。
- **最重要的功能增量**：OpenViking 增加跨 SDK 的内容读取和 MCP 多媒体返回；Hindsight 增加 BM25 长查询选择，并在发布后合并 pure-vector recall 与知识库导出；ReMe 增加 HTTP MCP、动态组件替换和插件化 Agent 集成。
- **Agent 集成**：MemOS 新增 DeepSeek Harness adapter；Mem0 发布 Strands `MemoryStore` 与 DeepSeek `search_memory`/`add_memory` 工具。Mem0 两条集成线默认加入匿名 telemetry，可用 `MEM0_TELEMETRY=false` 关闭。
- **本期可跳过**：Graphiti、Letta、Supermemory、Memori 没有确认的关键功能或 Breaking Change；文档、页面和普通问题修复不在正文展开。
- **新兴项目**：memorax-code 保持高增长并发布 0.1.9；deja-vu 提供 LongMemEval-S、LoCoMo 和 context benchmark 入口，适合作为“直接检索历史 Session”路线的低成本基线。

## 固定跟踪项目

### 1. OpenViking

- **已发布功能**：[v0.4.17](https://github.com/volcengine/OpenViking/releases/tag/v0.4.17) 对齐 Python、Go、TypeScript SDK 与服务端；`find` 和 list-mode `search` 增加 `read_content`；MCP `read` 可返回标准图片/音频 content block 与原始字节；`mkdir` 默认生成可检索 L0。
- **Breaking Change**：旧的 `viking://user/resources`、`viking://user/memories` 等 uid-less URI 被移除，需迁移到 `viking://~/...` 或 `viking://user/{user_id}/...`，客户端和服务端应成组升级。
- **已合并、未证明发布**：[#3213](https://github.com/volcengine/OpenViking/pull/3213) 增加资源 ACL、用户组授权和向量权限过滤；[#4412](https://github.com/volcengine/OpenViking/pull/4412) 将本地文件接入 external queue；[#4465](https://github.com/volcengine/OpenViking/pull/4465) 增加 OpenClaw durable-turn contract。
