观察区间：2026-08-24 至 2026-08-31（Asia/Shanghai）

## 本周摘要

- **已发布**：OpenViking 发布 v0.4.17，MemOS 发布 v2.0.32，ReMe 发布 v0.4.1.9；Mem0 在 Python SDK、DeepSeek Harness 与 Strands 集成上发布多个版本。

- **纯文档或营销变化**：Graphiti 主要是 README 定位重写，Supermemory 主要是 Web onboarding/dashboard 清理，Memori 与 Letta 的固定核心仓库没有本期记忆能力更新。
- 新兴项目中，**memorax-code** 约三天从 1,025 增至 1.1k Stars，并发布 0.1.9；**deja-vu** 的可运行 LongMemEval-S、LoCoMo 与 context benchmark 使其更适合作为“直接检索历史 Session”路线的成本基线。

## 固定跟踪项目

### 1. OpenViking

**已发布。** [v0.4.17](https://github.com/volcengine/OpenViking/releases/tag/v0.4.17) 于 8 月 28 日发布，标签指向 `e7f2fe5`。本次发布包含 92 个 commit，主要包括：

- Python、Go、TypeScript SDK 与服务端接口对齐；`find` 和 list-mode `search` 增加 `read_content`，MCP `read` 支持标准图片/音频 content block 与原始字节下载。
- `mkdir` 默认生成可检索 L0，缺失文件可由 `replace`/`append` 创建；记忆抽取指标按 type/action/result 拆分。
- 修复 Session archive 锁、memory patch/update、overview 索引、query planner 数组返回等可靠性问题。
- 存在明确 breaking change：旧的 `viking://user/resources`、`viking://user/memories` 等 uid-less URI 被移除，需要迁移到 `viking://~/...` 或显式 `viking://user/{user_id}/...`，客户端与服务端应成组升级。

**已合并但未证明发布。** v0.4.17 标签之后，默认分支继续合并 [#3213](https://github.com/volcengine/OpenViking/pull/3213) 资源 ACL/用户组授权与向量权限过滤、[#4412](https://github.com/volcengine/OpenViking/pull/4412) 本地文件进入 external queue、[#4465](https://github.com/volcengine/OpenViking/pull/4465) OpenClaw durable-turn contract，以及 [#4466](https://github.com/volcengine/OpenViking/pull/4466) glob 目录结果修复；这些不能写成 v0.4.17 已包含。

判断：本周出现了真正的版本级能力和兼容性变化。README 基线版本更新为 v0.4.17，但标签后的 ACL 等能力仍保持“已合并未发布”状态。

### 5. Hindsight

**已发布。** [v0.9.2](https://github.com/vectorize-io/hindsight/releases/tag/v0.9.2) 于 8 月 25 日发布，包含 native BM25 长查询项选择、DeepSeek Harness 支持、retention sweep 分批、mental model refresh 语义和多项 coding-agent 隔离修复。

**已合并但未证明发布。** v0.9.2 之后进入默认分支的主要变化包括：

- [#3819](https://github.com/vectorize-io/hindsight/pull/3819)：按 memory bank 关闭全文检索，支持 pure-vector recall。
- [#3809](https://github.com/vectorize-io/hindsight/pull/3809)：累积文档 body，避免每个 sub-batch 重建；官方博客给出大文档峰值内存说明，但这仍是项目方自报工程结果。

**纯文档变化。** [#3868](https://github.com/vectorize-io/hindsight/pull/3868) 是 cross-encoder reranking 博客，不等同于新增召回实现。

判断：发布后默认分支仍快速演进；下期必须检查这些变化是否进入 v0.9.3 或其他稳定 Release。
