# Agent Memory 周报 · 2026-08-28

观察区间：2026-08-21 至 2026-08-28（Asia/Shanghai）

## 本周摘要

- **OpenViking、MemOS、Hindsight、ReMe** 的默认分支最活跃，重点集中在 Agent 集成、记忆诊断、运行时稳定性和 MCP。
- **OpenViking** 增加了记忆抽取操作指标，并强化 Codex/Claude Code 插件诊断以及 delegated session 隔离。
- **MemOS** 继续加固本地插件运行时、最新 trace 读取和配套发布流程。
- **Hindsight** 增加按 memory bank 控制全文检索的开关，并改进大文档 retain 的内存使用。
- **Mem0** 新增 DeepSeek Harness、AWS Strands 集成，并开始公开 Dream/memory synthesis API 文档。
- 新兴项目中，**memorax-code** 创建不到一个月即超过 1,000 Stars；**MindMemOS、projectmem、deja-vu** 也值得进入观察池。

## 固定跟踪项目

### 1. OpenViking

当前：33,999 Stars；最新 Release [v0.4.16](https://github.com/volcengine/OpenViking/releases/tag/v0.4.16)。

确认进入默认分支：

- [#4410](https://github.com/volcengine/OpenViking/pull/4410)：增加 memory extraction operation metrics，为分析记忆写入阶段的操作分布和成本提供数据。
- [#4389](https://github.com/volcengine/OpenViking/pull/4389)：为 Claude Code 和 Codex 插件加入 `ov-memory-doctor` skill 与诊断脚本。
- [#4382](https://github.com/volcengine/OpenViking/pull/4382)：隔离 delegated session，避免其内容污染用户记忆。这属于重要的记忆归属/边界修正。
- 多项 MCP、embedding、配置诊断和 Agent 适配修复进入主分支。

判断：本周没有改变核心 L0/L1/L2 或递归检索模型，但可观测性、记忆隔离和 Agent 接入可靠性明显增强。

### 2. MemOS

当前：11,059 Stars；最新 GitHub Release [memos-local-plugin-v2.0.16](https://github.com/MemTensor/MemOS/releases/tag/memos-local-plugin-v2.0.16)，默认分支版本已继续推进到 2.0.32 相关改动。

确认进入默认分支：

- 本地插件运行时加固，覆盖辅助 reasoning capability、Hermes bridge 状态和 UTF-8 回归。
- 新增 `idx_traces_ts`，优化 newest-first trace 读取，避免阻塞事件循环。
- 自动化 MemOS 与 local plugin 的配对发布检查和发布流程。

判断：本周重点是工程稳定性和 release discipline，而不是新的记忆类型。对高频 trace/经验记忆场景，索引和事件循环修复具有实际价值。

### 5. Hindsight

当前：21,553 Stars；最新 Release [v0.9.2](https://github.com/vectorize-io/hindsight/releases/tag/v0.9.2)。

确认进入默认分支：

- [#3819](https://github.com/vectorize-io/hindsight/pull/3819)：每个 memory bank 可独立关闭全文检索，支持纯向量 recall。
- `retain` 改为累积文档 body，避免对子批次反复重建；团队报告其目标是控制大文档摄取峰值内存。
- 修复 transfer 时 mental model evidence id 映射，以及 Knowledge 页面跨 bank ID 作用域问题。
- Coding Agent 集成发布 v0.4.3，增强 Claude import 容错和 Prime Agent companion skill。

判断：本周变化集中在可配置召回、证据一致性和大文档工程效率，对生产部署有直接价值。

## 新兴项目雷达

以下项目不自动进入 Top 10；先进入观察池，连续跟踪活跃度、Star 增速、原创技术和可复现证据。

### 高优先级

- [memorax-ai/memorax-code](https://github.com/memorax-ai/memorax-code)：2026-08-01 创建，当前约 1,025 Stars；面向 Coding Agent，把工程经验、仓库知识和工作方式沉淀为跨任务记忆。创建时间短、增长最快，下一期重点检查其存储模型、License、评测和 Star 来源质量。
- [mindscale-noah/MindMemOS](https://github.com/mindscale-noah/MindMemOS)：2026-06-23 创建，约 958 Stars；提出 portable/self-evolving Memory OS，并已有对应技术报告。需要验证代码完成度和 benchmark 是否可复现。
- [riponcm/projectmem](https://github.com/riponcm/projectmem)：2026-05-09 创建，约 766 Stars；采用本地 append-only 事件日志记录 issue、attempt、fix、decision，并在重复失败方案前进行确定性提醒，技术边界清楚。
- [vshulcz/deja-vu](https://github.com/vshulcz/deja-vu)：2026-07-14 创建，约 731 Stars；不使用 LLM 和 Embedding，直接索引多种 Coding Agent 已有 Session 历史。它更像检索工具，但极简路线值得作为成本基线。

### 继续观察

- [ClaudioDrews/memory-os](https://github.com/ClaudioDrews/memory-os)：约 1,343 Stars，七层 Hermes Agent Memory OS；但最近推送停留在 2026-06-10，需观察是否恢复维护。
- [CodeAbra/iai-personal-memory-engine](https://github.com/CodeAbra/iai-personal-memory-engine)：约 814 Stars，本地个人记忆，覆盖多种 Coding Agent；需要补充架构和评测证据。
