# Agent Memory 周报 · 2026-09-07

观察区间：2026-08-31 至 2026-09-07（Asia/Shanghai）

## 本周摘要

- **Graphiti 已发布数据库行为变化**：core v0.30.0 / MCP v1.1.0 开始让 Neo4j 读写统一使用显式配置的数据库；使用非默认数据库的自托管 Neo4j Enterprise 部署需要检查旧数据是否落在 home database。
- **Hindsight 默认分支出现关键功能与 Breaking Change**：`retain` 支持有序文本、图片和文件 content block，并保存附件来源；旧 `/profile`、`/background` 接口改为返回 410，调用方必须迁移到 bank config API。以上尚未证明进入稳定 Release。
- **Cognee v1.5.4 已发布**：`add` 接口可直接接收文本和 Git 仓库 URL；同时移除 `repositories` 参数，并默认关闭本地文件根目录访问。
- **Agent/SDK 集成继续扩张**：Mem0 合并独立 Claude Code 0.3.0 插件；ReMe 合并图像资源转 daily memory；Supermemory 合并跨来源去重和七工具一致性；三者均未由本期 GitHub Release 证明已发布。
- **新兴项目**：memorax-code 和 deja-vu 保持发布与增长；Compartment v4.9.6 的单机共享 embedding daemon 显著改变本地多 Agent 部署成本，但性能数字仍是项目方自报。

## 固定跟踪项目

- **发布边界**：[v0.4.17.1](https://github.com/volcengine/OpenViking/releases/tag/v0.4.17.1) 仅是 AnyDoc 0.2 适配 hotfix，不包含上述功能；本期未确认新的 Breaking Change。

### 2. MemOS

**无关键变化。** [v2.0.33](https://github.com/MemTensor/MemOS/releases/tag/v2.0.33) 与 [local plugin v2.0.18](https://github.com/MemTensor/MemOS/releases/tag/memos-local-plugin-v2.0.18) 主要是偏好抽取和恢复可靠性修正，没有确认新的核心能力或 Breaking Change。

### 3. Graphiti

- **已发布功能**：[core v0.30.0](https://github.com/getzep/graphiti/releases/tag/v0.30.0) 的 `FactResult` 增加 `source_node_uuid`、`target_node_uuid` 和关联 episodes，调用方可以直接追溯事实两端实体与来源。
- **行为变化 / 迁移边界**：[MCP v1.1.0](https://github.com/getzep/graphiti/releases/tag/mcp-v1.1.0) 及 core 0.30.x 让读操作与写操作统一路由到配置的 Neo4j database。受影响的是配置了非默认数据库的自托管 Neo4j Enterprise：升级前应检查 home database 中是否遗留旧版本误写数据，并显式设置 `NEO4J_DATABASE`。

### 4. Letta

**无关键变化。** 固定仓库 `letta-ai/letta` 在观察区间没有默认分支提交或新 GitHub Release；该结论不覆盖 Letta Code、其他仓库或托管服务。

### 5. Hindsight

- **已合并、未证明发布**：[多模态 retain](https://github.com/vectorize-io/hindsight/commit/280f098202389ba4cdbca4aaf7c818e789163808) 支持有序 text/image/file content block、按内容哈希存储附件、VLM 抽取及事实级附件来源；Python、TypeScript、Go 客户端和控制台同步增加读取入口。
- **Breaking Change（未发布）**：[`GET/PUT /v1/default/banks/{bank_id}/profile` 与 `POST .../background`](https://github.com/vectorize-io/hindsight/commit/163fbb0ede6543af837b2c7c89e13012893d6a6b) 现在返回 410。disposition 与 `reflect_mission` 迁移到 `GET/PATCH .../config`；原 background 合并语义变为 `reflect_mission` 替换语义，CLI `bank background` 被移除。
- **已合并、未证明发布**：[Meta Model API](https://github.com/vectorize-io/hindsight/commit/30ce3b8d1139367b72092cf9dcf4116e9d1cd274) 成为一等 LLM provider；本期只有 coding-agents v0.5.0/0.5.1 Release，没有稳定 core Release，因此上述 core 变化不能写成已发布。

### 6. Mem0

- **已发布部署边界**：[Python SDK v2.0.20](https://github.com/mem0ai/mem0/releases/tag/v2.0.20) 与 [Node SDK v3.1.8](https://github.com/mem0ai/mem0/releases/tag/ts-v3.1.8) 将 OSS notices 改为仓库内静态配置和确定性 rollout，不再为 notice evaluation 调用 PostHog feature-flag API。
- **已合并、未证明 GitHub Release**：[Claude Code plugin 0.3.0](https://github.com/mem0ai/mem0/commit/71fba8d46436f88569d600f81a55208c38ad30b5) 通过 lifecycle hooks 本地采集、后台批量抽取和首轮 recall，区分共享项目记忆与个人记忆，并提供 repo/dir/mine 查询范围。
- **插件迁移边界**：0.2.x 的命令被六个 `/mem0:*` 命令替换，九个读写 MCP 工具收敛为本地只读 `search_memories`；官方说明新旧 Claude Code 插件不要同时运行。

### 7. Cognee

- **已发布功能**：[v1.5.4](https://github.com/topoteretes/cognee/releases/tag/v1.5.4) 的 `add` 接口可直接接收 `raw_data` 字符串和 Git repository URL；官方 Docker 镜像默认安装 `dlt` extra。
- **Breaking Change**：`repositories` 参数已移除，现有 API/CLI 调用需要按新签名调整。
- **安全与部署默认值**：`COGNEE_ALLOWED_LOCAL_FILE_ROOTS` 默认关闭；依赖本地文件摄取的部署必须显式启用并限制允许路径。启动日志现在会遮蔽 API token。

### 8. ReMe

- **已合并、未证明发布**：[Auto Resource 图像摄取](https://github.com/agentscope-ai/ReMe/commit/5c17874f7313d55431b3d124d548251483f35740) 使用 vision model 将图片转换为可检索 daily caption card，保留原图和 `source_resource`，并让图片更新/删除与原卡片联动。
- **评测资产**：[BEAM 与 LongMemEval](https://github.com/agentscope-ai/ReMe/commit/3f2eb6235f8950c5e4c84e868f29501c85b73dcb) 被拆成独立插件，便于按需安装和复现；本期 v0.4.1.10/0.4.1.11 Release 只包含一般修正，未证明上述能力已发布。

### 9. Supermemory

- **已合并、未证明发布**：[Python SDK 跨来源记忆去重](https://github.com/supermemoryai/supermemory/commit/03773c4f2ed562a16c697dfe996c7197ced3788e) 在 static、dynamic、search 三路内容间做规范化去重，并以 replace-not-append 更新注入上下文。
- **已合并、未证明发布**：[七工具一致性](https://github.com/supermemoryai/supermemory/commit/de3bbb3ce96c1fc92d33962fd93ac39580454cd2) 对齐 `searchMemories`、`addMemory`、`getProfile`、`documentList`、`documentDelete`、`documentAdd`、`memoryForget`，并增加 container-tag 作用域和删除安全检查。本期没有新服务器 Release。
