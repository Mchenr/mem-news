# Agent Memory 周报 · 2026-11-23

观察区间：2026-11-16 至 2026-11-23（Asia/Shanghai）

## 本周摘要

- **Hindsight v1.2.2 将 Knowledge Banks 与 Observation Tree 推入正式 Release**：多模态文档摄取、token-budget 检索、按 bank 的媒体配置和 OKF Markdown 导出不再只是默认分支能力；但 Knowledge Banks 仍受功能开关控制，Observation Tree 仍是实验性接口。v1.2.3 又补上大文件有界摄取与 Hermes 独立 `reflect_budget`。
- **Cognee v1.6.9—v1.6.10 同时扩大集成面并改变部署默认值**：新增 Dropbox、Vercel、Telegram、Evernote 与 Hermes Agent，旧 Slack history import 被删除；per-dataset PostgreSQL pool 收紧后，突发写入可能更快收到 `pool exhausted`，升级前需重审 pool 参数。
- **ReMe v0.4.2.3 发布资源包、应用自持 Chat 与可复现候选评测**；其后默认分支又合入 file-native proactive runtimes 和 ReMe Desktop，并删除旧 PA delivery、部分 alias 与插件入口契约，属于尚未发布的 Breaking Change。
- **默认分支出现两条重要基础设施路线，但都不能提前当稳定版使用**：Graphiti 增加原生嵌入式 Relate driver；OpenViking 增加多轨迹经验蒸馏、跨实例 PostgreSQL usage/audit 和带隐私引用的外部命令执行。两者最新 core Release 仍分别是 v0.31.2 与 v0.5.5。
- **新兴项目的高信号集中在权限、可迁移性与只读运行**：OKF Agent Memory v0.9.0 收紧 trust tier 与写保护；mneme 修复宿主 HTTP 访问围栏；dsh-mnemon 增加默认关闭的逐次写确认；Graphicle 提供真正不改 store 的只读模式；MemForge beta 首次提供可直接拉取的双架构 Release 镜像。

## 固定跟踪项目

### 1. OpenViking

- **已发布功能 / 独立前端包**：[@openviking/react 0.2.0](https://github.com/volcengine/OpenViking/releases/tag/react%400.2.0) 支持经验指标看板、会话自动创建、记忆策略、上下文 token 预算与保留消息数；该 Release 只证明 React 包发布，不证明 OpenViking core 已从 v0.5.5 升级。
- **已合并未发布 / Agent Memory**：[#7957](https://github.com/volcengine/OpenViking/pull/7957) 将多条结构化轨迹作为证据蒸馏 Agent experience，并加入 patch merge、trajectory/experience context provider 与 tau2 训练路径；提交中的 Retail 数字是项目方实验，未在本期统一复现。
- **已合并未发布 / 部署边界**：[#8231](https://github.com/volcengine/OpenViking/pull/8231) 让 token、retrieval、context-write 和 HTTP audit 可跨实例写入 PostgreSQL；管理员必须预建 schema，启动只验证、不建表也不迁表，生产 TLS 还需显式选择 `verify-ca` 或 `verify-full`。
- **已合并未发布 / 隐私边界**：[#7760](https://github.com/volcengine/OpenViking/pull/7760) 增加带 Privacy reference 的外部命令执行、输出遮罩和子进程回收；`OPENVIKING_PRIVACY_RUN_STRICT=1` 会拒绝参数位置的引用。该能力扩大了 CLI 可执行面，升级时应同时复核严格模式、重定向与管道行为。

### 3. Graphiti

- **已合并未发布 / 嵌入式部署**：[#2176](https://github.com/getzep/graphiti/pull/2176) 在 `main` 增加 `GraphProvider.RELATE`、本地 session/transaction 层和 Graphiti 搜索/图操作适配，提供不依赖外部 Neo4j/FalkorDB 的嵌入式 Relate 路线；该 optional extra 要求 Python 3.11+，同一 store 只有单个 writable connection lease，不能外推为多进程写或横向扩展能力。
- **Breaking Change / 迁移状态**：上周已合入的 Kuzu driver 删除仍未出 Release；本周 Relate 也晚于 [v0.31.2](https://github.com/getzep/graphiti/releases/tag/v0.31.2)。Kuzu 用户不能把尚未发布的 Relate 当作已验证的直接替代，需等待版本、迁移说明和持久化兼容性证据。

- **已发布功能 / 可观测记忆**：同一 Release 将 Observation Tree 作为 OKF Markdown bundle 导出，并补上 relative-link、非阻塞序列化与 Oracle scope 支持；接口仍标记 experimental。

### 7. Cognee

- **已发布功能 / v1.6.9**：[v1.6.9](https://github.com/topoteretes/cognee/releases/tag/v1.6.9) 增加 Dropbox、Vercel、Telegram、Evernote、重构后的 Slack source 与 Hermes Agent，并让 cognify 接受 JSON Schema graph model。
- **Breaking Change / 集成**：旧 Slack history import 已删除，依赖旧 API 或 vendor 内部 connector 路径的调用方必须迁到 `connectors/slack` 与新的 host/adapter 接口。
- **已发布功能 / v1.6.10**：[v1.6.10](https://github.com/topoteretes/cognee/releases/tag/v1.6.10) 增加 nested LLM call/caller capture，统一 chunker stamp，并收紧 per-dataset PostgreSQL pool 的 overflow 与等待边界。
- **Breaking Change / 部署默认值**：高并发短突发写入可能比旧版更快报 `pool exhausted`；需要按真实租户数和写入峰值复核 `VECTOR_POOL_ARGS`、dataset pool 和 `pool_timeout`。

### 8. ReMe

- **已发布功能 / v0.4.2.3**：[v0.4.2.3](https://github.com/agentscope-ai/ReMe/releases/tag/v0.4.2.3) 发布 application-owned Chat、proactive resource packages、可复现 benchmark 准备与 candidate evaluation，并统一 lossless streaming/collected replies；MemLens/MobileMem 对迭代上限结果的接受合同也随版本改变，横向比较必须写明 scorer 合约。
- **已合并未发布 / Breaking Change**：[#743](https://github.com/agentscope-ai/ReMe/pull/743) 增加 file-native proactive runtimes、ReMe Desktop、持久 session registry、语音/定时观察器与有界 durable event stream，同时删除旧 PA delivery API、`FileLink.predicate`、`dream.ProactiveResult` alias，并要求 package-only entry point 与 `plugin.yaml`；旧 workspace 还需重建派生图索引。
- **已合并未发布 / 结构边界**：后续 [runtime 重组](https://github.com/agentscope-ai/ReMe/commit/54fa3381d7fec4cdabb1b4092f5e755d7f62c769) 仍在推进 ReMe5，不能把文档预览或默认分支结构外推成下一个稳定版的最终 API。

### 9. Supermemory

- **已发布功能 / SDK wrapper，非 server**：官方 registry 已发布 [@supermemory/tools 3.2.0](https://registry.npmjs.org/@supermemory%2Ftools/3.2.0)、[supermemory-openai-sdk 1.1.0](https://pypi.org/project/supermemory-openai-sdk/1.1.0/) 与 [supermemory-pipecat 0.3.0](https://pypi.org/project/supermemory-pipecat/0.3.0/)；[#1906](https://github.com/supermemoryai/supermemory/pull/1906) 让 AI SDK、Mastra、OpenAI、Vercel、VoltAgent 等封装跨 turn 保留用户 prompt cache，Python OpenAI SDK 也改为 cache 失败不阻塞模型调用。
- **部署边界**：这些 registry 与提交只证明 wrapper/SDK 发布，不证明托管服务器或 Local 新版本部署；最新官方 Local Release 仍为 0.0.9。prompt 位置、同步保存时机与 speech-to-speech 可见记忆范围发生变化，接入方应做兼容性回归。
