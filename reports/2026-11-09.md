# Agent Memory 周报 · 2026-11-09

观察区间：2026-11-02 至 2026-11-09（Asia/Shanghai）

## 本周摘要

- **OpenViking v0.5.3 发布 Rules、Gateway 多副本与一组升级断点**：Rules（Beta）进入服务端与 Agent 工具面，Gateway 可基于 Redis 多副本运行；旧 `viking://session/...` 路径、旧会话迁移接口和单成员 Group API 被移除，身份校验也默认收紧。升级前必须先处理 0.3.x 遗留会话与客户端路由。
- **Hindsight v1.2.0 把 decision model、Agent 集成和可观测扩展推入稳定版**：OpenClaw/Hermes 获得更完整的 memory/knowledge 工具，decision-model recall 支持 prune、dedup 和 hosted provider，MCP 对齐这些参数；默认 reranker 迁到 `hindsight-ai/hs-rerank-1`，部署方应重新核对有效模型与数据路径。
- **Cognee v1.6.7 默认拒绝高风险摄取输入**：HTTP API 不再默认接受数据库连接串、服务端文件路径和 `s3://` 输入；需要这些能力的部署必须显式开启对应 gate。该版同时修正 scoped retrieval，并为 DLT 列写入 graph anchors。
- **ReMe v0.4.2.2 同时改变 Codex 集成与安全边界**：Codex wrappers 改为共享 application-owned app-server；benchmark Python 不再暴露为 HTTP/MCP，且无可用 sandbox 时禁止回退到宿主执行。发布还加入 Qoder 插件、Codex session/proactive message 与可复现实验工作区；统一 lossless event stream 则在 Release 后合并，尚未发布。
- **新兴项目继续高速分化**：tigerless 维持文件事实源与独立 Manage 层，deja-vu 强化 coding-session X-Ray，mneme 发布逐事实 profile 与显式 pin，OKF v0.8.0 则把 scope 隔离和并发写保护写入 Git-native memory 契约；这些 benchmark 仍以项目方自测为主。
