# Agent Memory 周报 · 2026-11-16

观察区间：2026-11-09 至 2026-11-16（Asia/Shanghai）

## 本周摘要

- **OpenViking v0.5.5 同时扩大部署能力与默认写权限**：新增 pgvector、PostgreSQL PathLock 和多节点协调，但 Gateway 默认改为开放八个写工具；Git 导入 SSRF 防护、Kafka 配置迁移、Skill 更新不回滚和部分导入语义也已进入稳定版。升级前应先显式核对 `disabled_tools`、导入完成判定和配置迁移。
- **Cognee v1.6.8 把跨租户修复和 fail-closed 摄取推入稳定版**：上周仍归为 `dev` 的六类跨用户/跨租户修复已随 Release 发布；URL/remote clone 必须显式 opt-in，cloud telemetry 也改为 metadata-only allowlist，但该隐私边界只适用于 `TELEMETRY_ORIGIN=cloud`。
- **Hindsight v1.2.1 发布写前审核、双 embedder、在线 re-embed 和自定义 provider**；随后合入的多模态 Knowledge Banks 仍默认关闭，Observation Tree 仍是 experimental API，两者都没有新 Release 证明已发布。
- **Graphiti 默认分支形成尚未发布的迁移断点**：Kuzu driver、extra 和 provider 已删除；同图并发摄取和 `identity_properties` 实体合并已合入但均晚于 v0.31.2，不能提前按稳定版使用。
- **新兴项目继续分化**：MemoraX Code、mneme、dsh-mnemon 与 Graphicle 发布了有边界的新能力；tigerless 的 durable Write queue 仍只有默认分支证据。deja-vu 因创建于 2026-07-14，已自然退出本期 120 天窗口。

## 固定跟踪项目

### 1. OpenViking

- **已发布功能 / v0.5.4—v0.5.5**：[v0.5.4](https://github.com/volcengine/OpenViking/releases/tag/v0.5.4) 发布 Streamable HTTP MCP、Rule Search、MySQL Watch、记忆整理与 Account/GLOBAL 访问控制；[v0.5.5](https://github.com/volcengine/OpenViking/releases/tag/v0.5.5) 新增 pgvector、PostgreSQL PathLock、多节点协调、快照路径索引、`recall_peer_scope`、`capture_memory_types` 和批量标签。
- **Breaking Change / 默认权限**：v0.5.5 的 Gateway `disabled_tools` 默认变为空，默认开放 `remember`、`write`、`edit`、`add_resource`、`add_skill`、`forget`、`set_acl`、`cancel_watch`；`X-OpenViking-Context` 只能继续收窄权限。未保存 `default` Profile 或未显式配置 `disabled_tools` 的账户必须复核。
- **部署与安全边界**：Git clone/fetch 不再跟随重定向并拒绝回环、链路本地、保留地址和云元数据地址；Kafka 上报从 Nacos/外部 JSON 迁入 `ov.conf`；Skill 更新失败不再自动回滚；首次 `strict=false` 导入可返回 `partial`，调用方还需检查 `import_complete`。
- **独立包 / 预发布**：[@openviking/react 0.1.12](https://github.com/volcengine/OpenViking/releases/tag/react%400.1.12) 发布 Console HITL 与字段验证，并移除 SSR/hydration 支持；[SuperAgent 0.5.3-preview](https://github.com/volcengine/OpenViking/releases/tag/openviking-superagent%400.5.3-preview) 仍是预发布，不能外推为稳定跨平台能力。

### 2. MemOS

- **已发布功能 / v2.0.36**：[v2.0.36](https://github.com/MemTensor/MemOS/releases/tag/v2.0.36) 发布 per-model Redis GCRA rate limiting，恢复 OpenClaw 自动 memory hooks，修复跨 cube recall，并让 PostgreSQL graph storage 对齐当前 API。
